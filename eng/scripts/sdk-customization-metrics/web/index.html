Collection diagnostics & technical details

Scan budgets are not collection failures. The collector captures up to 20 source/context files, 16 KB per file, and 100 KB per package. Files outside these budgets remain linked below, grouped separately from actual errors. Their contents were not analyzed. Coverage remains partial even when all eligible files fit.

Query and download

SQLite database (includes public scan history) | Current effective records (JSON)

Run this SQL locally with SQLite or the collector's read-only query command:

SELECT package, module_major, subtype, explanation, snippets_json
FROM accepted_customizations
WHERE language = 'java' AND category = 'LRO'
ORDER BY package, subtype;

No browser API secrets or AI chat backend. Filters and search run entirely in your browser.

Structured query: choose language/service/library/category/review status and AND-matched text (including subtype, symbol or captured snippet). Filters, observation, history range and selected instance are shareable in the URL. This is not natural-language AI chat.

Historical SQL example 
SELECT o.observed_at, f.identity, f.category, f.status
FROM observation_findings f
JOIN observations o ON o.id = f.observation_id
WHERE f.counted = 1 AND f.category = 'LRO'
ORDER BY o.observed_at;
