## Where handwritten code lives

Generated Go files start with a `// Code generated by ... DO NOT EDIT.` header (usually also
named `zz_*.go`). Any other non-test `.go` file in the module is handwritten, wherever it
lives. That includes `custom_*.go` files, handwritten files inside `internal/generated/`,
and higher-level packages (such as `azblob/blockblob`) layered over generated operations.

## Signals

| Signal                                        | Meaning                                               |
| --------------------------------------------- | ----------------------------------------------------- |
| `// Code generated ... DO NOT EDIT.` header   | Generated file                                        |
| `zz_` file name prefix                        | Generated file                                        |
| `custom_*.go`                                 | Handwritten customization (common convention)         |
| Handwritten file inside `internal/generated/` | Still handwritten; the folder name is not a guarantee |

## Not customizations

- Files with the generated header.
- `_test.go` files, `testdata/`, examples (`example_*_test.go`), `version.go`/`constants.go`
  if generated.
